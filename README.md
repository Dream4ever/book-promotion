# 出版社推广商报备系统

本项目采用 `Nuxt.js + Vue 3 + Tailwind CSS v3` 构建全栈应用，通过 Nuxt BFF 接口将数据保存到 Supabase。

## 已实现功能

- 学校名单维护：省份、学校名称
- 书目名单维护：ISBN、书名、定价
- 推广商名单维护：推广商名称、联系人、联系电话、代理期间、任务量、省份接单配置
- 报备管理：同一个学校的同一个书目只能报备一次
- 数据修改：学校、书目、推广商、报备记录均支持编辑
- 弹窗操作：新增和编辑统一在弹出窗口中完成
- 批量删除：各类列表支持勾选后批量删除
- 批量导出：支持导出筛选结果和已选数据到 Excel
- Excel 导入：支持学校、书目、推广商
- 导入预览：Excel 解析后先预览确认，再正式写入 Supabase
- 搜索筛选：学校、书目、推广商、报备记录均支持关键词搜索
- 模糊查询：报备时输入关键词，下拉选择学校、书目、推广商
- 分页显示：各类列表默认每页 20 条
- 统计报表：支持按省份、推广商、书目筛选并生成统计结果
- Supabase 持久化：所有数据写入 Supabase

## 启动

```bash
npm install
npm run dev
```

本地默认地址：`http://localhost:3000`

本地 API 与前端同源，接口路径为 `/api/*`。

生产构建：

```bash
npm run build
npm start
```

## Excel 字段建议

### 学校

- `省份`
- `学校名称`

### 书目

- `ISBN`
- `书名`
- `定价`

### 推广商

- `推广商名称`
- `联系人`
- `联系电话`
- `代理期间`
- `任务量`
- `省份配置`

`省份配置` 示例：

```text
浙江:是, 江苏:否
```
